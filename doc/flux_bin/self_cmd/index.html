cargo flux self: installing, updating, and uninstalling Flux from prebuilt releases.

Releases are published by the nightly workflow: the moving nightly release, and dated nightly-yyyy-mm-dd copies. Each has a manifest.json, see ReleaseManifest, and one flux-<target>.tar.gz archive per target, holding a sysroot directory.

uninstall 🔒

update 🔒
Installs the release tag, unless it’s already installed. The release’s archive is extracted next to the default sysroot, and the cargo-flux in it installs it with cargo flux self install, so the installation is always done by the version being installed.
