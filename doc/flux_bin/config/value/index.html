flux_bin::config

Module value 

Source
Expand description

Untyped configuration values that remember where they were written.

Configuration files are parsed into ConfigValue trees in which every node carries its Location. Trees from different files are merged and then deserialized into typed settings. Deserialization errors point to the location of the offending value, and fields of type Located<T> keep the location of their value, e.g., to resolve a relative path against the file that defines it.
