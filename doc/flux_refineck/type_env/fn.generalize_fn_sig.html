fn generalize_fn_sig(sig: &PolyFnSig) -> PolyFnSig
Expand description

Generalizes a fn pointer signature to one with the same (rust) shape where all refinements are holes, e.g., for<n> fn(i32[n]) -> i32[n + 1] becomes fn({v. i32[v] | *}) -> {v. i32[v] | *}. The refinement params of the signature are dropped, and so are the requires, ensures and no_panic (which could mention them). The region vars are kept: they come before the refinement params in the binder, so dropping the latter doesn’t shift them.

This is the same template that refining the rust signature with Refiner::with_holes would produce (see the Refine impl for ty::FnSig), but it doesn’t need a refiner.
