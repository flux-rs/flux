Installing and uninstalling a sysroot, shared by cargo x install and cargo flux self.

Every function prints what it does to stderr, in the form of the equivalent shell command.

link_binaries
Links the LINKED_BINARIES in sysroot from cargo’s bin directory, replacing whatever is there. The links point to sysroot itself rather than to the directory it resolves to, so they keep working when sysroot is replaced. Windows doesn’t have unprivileged symlinks, so there the binaries are copied instead.
