KVar
In theory a kvar is just an unknown predicate that can use some variables in scope. In practice, fixpoint distinguishes a list of leading arguments, the kvar’s self arguments, from the rest, which we call the scope. Fixpoint only instantiates qualifiers whose first parameter is a self argument, so a kvar without self arguments can only be solved to true or false. The number of self arguments is passed to fixpoint with the :self annotation.
