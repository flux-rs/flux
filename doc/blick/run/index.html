Module run 

Source
Expand description

Running Flux on a program: cargo x run <file> -- -Fdump-checker-trace=debug from the repository root, so Flux and its sysroot are rebuilt when needed, exactly as on the command line. Its output is streamed as it is printed; Flux writes the trace to a file, and rustc the MIR of each body (-Zdump-mir=renumber: the body borrow checking, and so Flux, works on) to a directory.
